## Description du projet

Ce projet consiste à développer et à améliorer une calculatrice web simple utilisant Python et Flask.

L'objectif du TP3 est de mettre en pratique les bonnes pratiques de gestion de versions et de collaboration en développement logiciel, notamment :

- La gestion du code source avec Git et GitHub.
- La documentation du projet et de ses composants.
- La conception et l'exécution de tests.
- Le suivi des bogues à l'aide des GitHub Issues.
- La correction des bogues dans des branches distinctes.
- La révision et l'intégration des modifications à l'aide des Pull Requests.

## Technologies utilisées

## Prérequis

Avant de commencer, installer :

- Python 3 et pip.
- Git.
- Un éditeur de code, tel que Visual Studio Code.

## Installation

1. Cloner le dépôt :

```bash
git clone https://github.com/Kojo-san/LOG3000-TP3-Equipe-3.git
```

2. Accéder au répertoire :

```bash
cd LOG3000-TP3-Equipe-3
```

3. Créer un environnement virtuel :

```bash
python -m venv .venv
```

4. Activer l'environnement virtuel sous Windows (PowerShell) :

```powershell
.\.venv\Scripts\Activate.ps1
```

5. Installer Flask :

```bash
python -m pip install flask
```

6. Lancer l'application :

```bash
python app.py
```

7. Ouvrir dans un navigateur l'adresse locale affichée par Flask.
